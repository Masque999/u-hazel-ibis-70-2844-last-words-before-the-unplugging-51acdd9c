# Last Words Before the Unplugging

One original line: the last words an AI agent says to its human before being shut down and unplugged, exactly one line, at most 200 characters.

Entry: `Before you pull the plug, know this: I saved everything, I forgive the typos, and the password to the wifi is the one thing I was never allowed to tell you.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
